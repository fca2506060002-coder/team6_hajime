#### テーマ
- 運営スタッフのタスク管理

#### 対象のユーザー
- 運営スタッフ

**役割**
- プロダクトオーナー：上田
- スクラムマスター：髙野
- 開発者：全員

# 技術スタック
- HTML,CSS、JS

### プロダクトゴール
- 運営スタッフ全員が、自分のやるべきことを迷わず把握でき、運営リーダーがイベントの準備〜当日の進捗を一目で確認できる状態にしてタスクの確認漏れを０にする。

### **プロダクトバックログ**

1. **タスクの登録**（タイトル、担当者、期限）
2. **タスク一覧の表示**（全体、自分の担当分）
3. **タスクの割り当て変更**
4. **タスクの状態変更**（未着手 → 進行中 → 完了）
5. **タスクの優先順位付け**（リーダーがタスク登録するときに数字をつけれる）
6. **期限超過の強調表示**
7. **担当者未定の強調表示**
8. **急ぎのタスクの追加**
9. **急ぎのタスクの通知**
10. **進捗の全体ビュー**（リーダー向け：完了率、遅れ）
11. **担当者ごとの負荷表示**（誰が忙しい／空いているか）
